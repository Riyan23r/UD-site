# 🏢 United Dreams

Welcome to the **United Dreams** apartment website.

United Dreams is a residential apartment website designed to provide information about the apartment community, its facilities, location, and more.

## ✨ Features

- 🏢 Apartment information
- 📍 Location information
- 🗺️ Google Maps location
- 🖼️ Photo gallery
- 📱 Mobile-friendly design
- 📲 Installable as an app (PWA)
- ⚡ Offline support

## 📱 Install the Website

On supported devices:

1. Open the United Dreams website.
2. Open your browser menu.
3. Select **Install app**.
4. United Dreams will be added to your device like an app.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- GitHub Pages
- Progressive Web App (PWA)
